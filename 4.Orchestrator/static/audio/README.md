# Filler audio clips

Generated by `1.Language normalizer/scripts/generate_filler_audio.py` -
derived Bhashini TTS output, not hand-written source, but committed here so
the feature works out of the box for anyone on this branch without needing
a live Bhashini key on hand.

Currently generated: en, hi, bn, or. Still missing: ur, ne, mai (their
Bhashini translate/TTS calls failed when this was last run - re-run the
script and check its per-language output to fill these in). Santali ("sat")
has no Bhashini TTS coverage on this key and is permanently skipped.

Missing/failed languages aren't a hard failure - the frontend's
`playFiller()` just fails silently (no clip plays) for whichever language
has none yet.

Re-run the generator (needs the Language normalizer's `.env` / Bhashini
key) any time the filler wording changes or a missing language gets fixed:
```
cd "1.Language normalizer"
python scripts/generate_filler_audio.py
```
